Q2) Get Student Name and Marks for 3 Subjects; Calculate Total & Average
-------------------------------------------------------------------------

File: Q2.sh

Script:
echo "Enter the name : "
read name
echo "Enter Sub-1 marks : "
read sub1
echo "Enter Sub-2 marks : "
read sub2
echo "Enter Sub-3 marks : "
read sub3
sum=$(($sub1+$sub2+$sub3))
avg=$(($sum/3))
echo "Total : " $sum
echo "Average : "$avg

Run:
chmod 777 Q2.sh
./Q2.sh

Output:
Enter the name :
Sanka
Enter Sub-1 marks :
75
Enter Sub-2 marks :
80
Enter Sub-3 marks :
85
Total :  240
Average :  80

Q3) Create a Calculator with Arithmetic Operations
--------------------------------------------------

File: Q3.sh

Script:
echo "Enter num1 : "
read num1
echo "Enter num2 : "
read num2
sum=$(($num1+$num2))
sub=$(($num1-$num2))
div=$(($num1/$num2))

chmod 777 Q3.sh
./Q3.sh

Output:
Enter num1 :
50
Enter num2 :
5
Sum :  55
Sub :  45
Div :  10
Mul :  250

Q4) Get Day Based on Number Input
----------------------------------

File: Q4.sh

Script:
echo "Enter the number : "
read num
case $num in
1)echo "Monday";;
2)echo "Tuesday";;
3)echo "Wednesday";;
4)echo "Thursday";;
5)echo "Friday";;
6)echo "Saturday";;
7)echo "Sunday";;
*)echo "Unrecognized number!";;
esac

Run:
chmod 777 Q4.sh
./Q4.sh

Output:
Enter the number :
-9
Unrecognized number!

Enter the number :
3
Wednesday

Q5) Verify if Username is "Mino"
--------------------------------

File: Q5.sh

Script:
username="Mino"

Q6) Compare Two Numbers
------------------------

File: Q6.sh

Script:
echo "Enter two numbers : "
read num1 num2
if(($num1 > $num2)); then
  echo "$num1 is greater than $num2"
elif(($num1 < $num2)); then
  echo "$num1 is less than $num2"
else
  echo "Both numbers are same"
fi

Run:
chmod 777 Q6.sh
./Q6.sh

Output:
Enter two numbers :
5 7
5 is less than 7

Enter two numbers :
7 5
7 is greater than 5

Q7) Simple Calculator Using 'expr'
----------------------------------

File: Q7.sh

Script:
echo "Enter num1 : "
read num1
echo "Enter num2 : "
read num2

sum=$(expr $num1 + $num2)
sub=$(expr $num1 - $num2)
div=$(expr $num1 / $num2)
mul=$(expr $num1 \* $num2)

echo "Sum : $sum"
echo "Sub : $sub"
echo "Div : $div"
echo "Mul : $mul"

Run:
chmod 777 Q7.sh
./Q7.sh

Output:
Enter num1 :
12
Enter num2 :
4
Sum : 16
Sub : 8
Div : 3
Mul : 48
